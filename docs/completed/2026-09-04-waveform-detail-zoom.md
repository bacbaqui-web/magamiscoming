# 명시적 확대와 PCM 상세 파형

- 자동 확대 대신 버튼/휠, 유지되는 1~64배와 좌우 구간 이동을 구현했다.
- 프런트 viewport API와 별도 분석 서버의 약 1ms PCM 최소/최대 저장·집계를 연결했다.
- 구버전 분석은 단일 큐 재분석, 수동 편집은 보존한다. 원본 음원은 저장하지 않는다.
- 실제 곡 1곡 재분석/API 응답과 격리 Edge에서 실제 데이터 확대·드래그·저장을 확인했다.
- 격리 테스트는 로컬 네트워크 권한을 프록시로 우회했다. 사용자 브라우저 권한·음악적 후렴 정답·청각 DJ 품질은 별도다.
