# 음파 세 핸들·디제잉

## 승인 범위

초록 시작/끝과 흰 1절 삼각형, 선택 영역 채움 동기화, 이어듣기를 비초록 영역 디제잉으로 변경.
1절 위치는 저장만 하며 1절 재생 모드는 후속 구현이다.

## 결과

- 기존 수동 스키마의 선택적 `verseEnd` 확장, Lab/Cloud 기존 저장 경로 유지.
- 비초록 tail/head와 최대 페이드 시간 중 최솟값으로 전환하며 초록 부분은 겹치지 않는다.
- 저장 수동값 우선, 없으면 세션 자동 분석값. 둘 중 구간이 없으면 곡 끝에서 순차 전환.
- media time 기반 fade, pause/resume, seek 시 전환 취소, 대기 Player 시작 timeout을 처리한다.
- 로컬 Edge에서 세 핸들 키보드 조작/색칠/삼각형 시각 확인, 새로고침 저장 유지 확인.
- 실제 두 곡 청각 fade와 포인터 드래그 품질은 미검증. YouTube seek/tick은 샘플 정밀 믹서가 아니다.

현재 기준은 `../architecture/workmusic.md`, 최근 검증은 `../99_recent_task.md`를 따른다.
