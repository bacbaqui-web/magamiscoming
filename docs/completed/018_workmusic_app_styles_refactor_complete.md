# Sprint 16. 노동요·App 공통 스타일 분리와 구조 리팩토링 완료

## 결과

노동요와 App 공통 CSS 소유권을 분리하고, 코드·자동 검사·로컬 브라우저 범위에서 전체 구조 리팩토링을 완료했다.

## 변경

- 노동요 내부 탭, 목록, 커버 흐름, 플레이어, 진행 표시, 재생·음량·이어듣기 컨트롤, 하단 리모컨과 반응형 규칙을 `styles/workmusic.css`로 이동
- App Shell, 공통 메인·내부 탭, 공통 모달·드래그 영역, footer, Drive 저장 표시와 전역 반응형 규칙을 `styles/app.css`로 이동
- `styles.css`의 모든 선언을 소유권 파일로 옮긴 뒤 파일과 기존 로드 항목 제거
- Styles Architecture, Source Map과 Sprint 문서 최종 동기화

## 보존한 계약

- CSS 값, 선택자, 선언 순서, 각 소유권 내부 규칙 상대 순서와 미디어 조건
- 노동요 DOM, JavaScript, 저장 데이터, 재생과 두 Player 이어듣기 계약
- 다른 기본 탭과 사용자 정의 탭의 공통 내비게이션·모달·footer 표시

## 검증

- 이동 직후 App 422줄, 노동요 1,584줄이 원본 소유권 구간과 바이트 단위로 일치하고 합계 2,006줄임을 확인
- Prettier 적용 후 문자열 따옴표와 긴 선언 줄바꿈만 정규화하고 CSS 값·선택자·선언 순서를 재검토
- `npm test`: 62개 통과
- `npm run lint`: 통과
- `npm run format:check`: 통과
- `git diff --check`: 통과
- 데스크톱 1280×900과 모바일 390×844에서 7개 기본 탭, 프로필, 사용자 정의 탭 모달, 달력 작업·설정 모달, 노동요 빈 목록·커버 흐름·진행 표시·volume/seamless·리모컨 확인
- 로컬 브라우저 콘솔 오류 없음. 기존 Tailwind CDN 운영 경고만 확인

## 미검증

- 실제 Drive 파일 업로드·다운로드·삭제와 CLIP 폴더 선택
- 실제 YouTube 영상 재생, 오류 영상 건너뛰기와 두 Player 이어듣기의 청각 전환
