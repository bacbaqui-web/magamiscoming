# Sprint 15. CLIP·북마크·달력 스타일 분리

## 결과

CLIP 뷰어, 북마크와 달력 전용 스타일을 기능별 파일로 순수 이동했다.

## 변경

- 북마크 내부 탭·Masonry 목록·이미지/제목 모달 CSS 분리
- 달력 주간·월간 화면, 공휴일·기간/반복 작업·설정 모달 CSS 분리
- CLIP 툴바·빈 상태·파일 드래그 표시와 모바일 CSS 분리
- `index.html` stylesheet 로드 순서 연결
- Source Map과 스타일 Architecture 동기화

## 보존한 계약

- CSS 값, 선택자, 선언 속성 순서와 미디어 조건
- 각 기능 내부 규칙의 상대 순서와 공통 선언의 기존 위치
- 공용 모달·내부 탭·드래그 영역 스타일 소유권
- DOM, JavaScript 동작과 저장 계약

## 검증

- 원본 대상 블록 37,219바이트와 잔여 `styles.css`를 자동 비교하고, 분리 미디어 래퍼를 제외한 선언 블록 동등성 확인
- 자동 테스트 62개, ESLint, Prettier와 diff 검사 통과
- 데스크톱과 390×844 모바일에서 북마크 빈 목록·설정 모달, 달력 주간·월간·공휴일·작업/설정 모달, CLIP 빈 상태 확인
- 콘솔 오류 없음. 기존 Tailwind CDN 운영 경고만 확인

## 미검증

- 실제 데이터가 있는 북마크 카드와 이미지 모달
- 실제 CMC 폴더 선택과 파일 드롭
- 포인터 드래그 중 상태와 터치 달력 제스처
- Sprint 16 노동요·App 공통 스타일의 최종 시각 회귀
