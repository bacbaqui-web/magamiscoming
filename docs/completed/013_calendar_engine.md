# Sprint 11 달력 Engine

## 결과

달력 작업과 기준일·보기 상태를 Engine 한 곳으로 모으고 DOM, 저장 연결과 날짜 계산을 분리했다. 기존 저장 스키마, 공휴일, 주간·월간 화면, 모달과 공개 전역 계약은 유지했다.

## 구현

- CalendarEngine이 작업, 완료 상태, 기준 주·월, 보기 방식과 주 시작일을 소유한다.
- Composer가 기존 주간·월간 DOM, 작업·설정 모달과 휠·키보드 제스처를 유지한다.
- Controller가 작업 CRUD·완료 변경, 보기 이동과 설정 변경을 Engine에 요청하고 저장 호환 상태를 게시한다.
- Helper가 KST 날짜, 주·월 범위와 기간·반복 작업 계산을 맡는다.
- Cloud State의 작업 삭제와 Compatibility 렌더가 Controller를 통해 Engine 상태를 변경한다.
- 달력 선로드와 나머지 데이터 지연 로드 순서는 변경하지 않았다.
