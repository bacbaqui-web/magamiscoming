# Sprint 14. 작은 탭 스타일 분리

## 결과

뽀모도로, 메모, 프로필과 사용자 정의 탭 전용 스타일을 기능별 파일로 순수 이동했다.

## 변경

- 프로필·사용자 정의 탭 CSS 453줄 분리
- 뽀모도로 기본·모바일 CSS 182줄 분리
- 메모 탭·편집 영역 CSS 85줄 분리
- `index.html` stylesheet 로드 순서 연결
- Source Map과 스타일 Architecture 동기화

## 보존한 계약

- CSS 값, 선택자, 선언 순서와 미디어 조건
- 대상 기능끼리의 상대 cascade 순서
- DOM, JavaScript 동작과 저장 계약
- 공용 내부 탭·설정 스타일의 기존 위치

## 검증

- 원본에서 이동한 14,007바이트와 새 파일 내용, 잔여 `styles.css`를 자동 비교해 정확히 일치
- 자동 테스트 62개, ESLint, Prettier와 diff 검사 통과
- 데스크톱과 390×844 모바일에서 대상 화면 레이아웃·색·hover·focus·모달 상태 확인
- 콘솔 오류 없음. 기존 Tailwind CDN 운영 경고만 확인

## 미검증

- 실제 로그인 프로필 정보
- 기존 사용자 데이터로 생성된 사용자 정의 탭 행
- Sprint 15~16 대상 기능의 최종 시각 회귀
